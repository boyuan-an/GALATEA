# Example asset attribution

The video was generated by the GALATEA project with Seedance from its own
fixed-camera capture. The reference RGB image, depth image, and intrinsics are
from that project capture. These project-provided example assets accompany
GALATEA under the repository [LICENSE](../../../LICENSE).

The power-drill geometry derives from **035_power_drill** in the
**Yale-CMU-Berkeley (YCB) Object and Model Set**, by Berk Calli, Arjun Singh,
Aaron Walsman, James Bruce, Konrad Konolige, Siddhartha Srinivasa,
Pieter Abbeel, and Aaron M. Dollar and their collaborators.

- Source: [YCB object models](https://www.ycbbenchmarks.com/object-models/).
- License declaration: [official YCB data index](https://ycb-benchmarks.s3.amazonaws.com/index.html).
- Model license: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
- Changes: scaled to match the project's physical drill prop, simplified to
  5,000 triangles, and exported without textures. The model's separate CC BY
  4.0 license continues to apply to this derivative geometry.

Please credit the YCB authors when redistributing the mesh. No endorsement by
the YCB authors is implied.
